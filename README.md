# APP_ControleFinanceiro

Problema e Usuário Imaginário
O aplicativo resolve a falta de clareza e controle sobre as finanças pessoais no dia a dia. O "usuário imaginário" é um jovem adulto, estudante ou profissional, que precisa de uma ferramenta ágil, visual e sem jargões contábeis para registrar gastos cotidianos e saber exatamente para onde o dinheiro está indo.

Motivação de Uso Diário
Alguém abriria o aplicativo hoje para verificar rapidamente seu saldo disponível na "Visão Geral" antes de tomar uma decisão de compra, ou para registrar uma despesa que acabou de acontecer, como "Combustível". A pessoa abriria novamente amanhã porque o controle financeiro depende de consistência; o aplicativo precisa ser acessado diariamente para que novos gastos (como "Restaurante") sejam lançados e o extrato de contas continue refletindo a realidade.  

A Principal Funcionalidade
A única coisa que o aplicativo precisa fazer perfeitamente é permitir a inserção de uma nova transação de forma extremamente rápida e sem atrito. Se o usuário achar o processo de registrar um gasto demorado ou confuso, ele abandonará o hábito. A fluidez da tela de cadastro é o que sustenta o uso contínuo.

Geração de Valor e Monetização
Em um cenário real, o aplicativo poderia ser monetizado através de um modelo freemium. As funções básicas de registro manual e visualização de saldo seriam gratuitas, mas o usuário pagaria uma assinatura para desbloquear recursos avançados, como categorização ilimitada, relatórios complexos, sincronização automática com contas bancárias ou exportação de dados. Outra via seria a indicação de produtos financeiros (como cartões de crédito ou investimentos) baseados no comportamento de consumo.

Decisões de Tela Baseadas nas Respostas
Como o objetivo é oferecer respostas financeiras imediatas, a tela inicial (Dashboard) foi projetada para mostrar o saldo de "R$ 2.450,00" em grande destaque no topo, em vez de esconder essa informação atrás de menus ou poluí-la com gráficos complexos logo de cara. Abaixo do saldo, o usuário já visualiza suas últimas transações (como a despesa de "-R$ 100,00") para entender o impacto recente. Para garantir a rapidez exigida pela funcionalidade principal, a tela de "Nova Transação" foca no essencial: botões fáceis de alcançar para "Despesa (-)" ou "Receita (+)", um campo amplo para o valor monetário e um botão em destaque para "SALVAR TRANSAÇÃO" na parte inferior
